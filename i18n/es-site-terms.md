# Site term sheet - Spanish (es-419, neutral)

Scope: buildwithjesus.com (site copy, not the guide).
Base: the guide's Spanish term sheet (same voice, LOCKED items) extended with site terms.

## Voice

- Register: **tú** (informal, singular). Neutral Spanish, LatAm-friendly: no vosotros,
  no strong regionalisms. Warm, plain, short sentences.
- No em dashes or en dashes anywhere in prose (no —, –, &#8211;, &#8212;); comma, colon or
  period instead. Hyphens inside loans (Wi-Fi) stay.
- No "adolescente"/"adolescencia" ever. Western digits; entities stay entities.

## Term locks (site)

- young people -> los jóvenes (young person -> un joven); adults -> los adultos
- church -> iglesia; community -> comunidad; charities -> organizaciones benéficas;
  religious schools -> colegios religiosos; homeschool families -> familias que educan en casa
- agent -> Agent (keep English, capitalised, per the guide editions); the agent (nav) -> Agent
- leaders guide -> guía para líderes; workshop -> taller; programme -> programa
- the guide -> la guía; The Guide (footer) -> La guía
- build (verb) -> construir; build (the activity) -> construir; build day -> día de construir
- the Eight Essentials -> los ocho esenciales; movements: Learn. Build. Give. -> Aprender. Construir. Dar.
- Follow Jesus -> Seguir a Jesús; Give them away -> Regalarlos
- school term -> trimestre; laptop -> laptop; phone -> teléfono; screen -> pantalla;
  feed -> feed; message -> mensaje; notification -> notificación; screen time -> tiempo de pantalla

## Scripture policy on translated pages

The spaRV1909 edition ships and is verified, so quotes come from it exactly, from the local
file, with the translation named (RV1909) and Spanish book names. No English fallback needed.

## Meta

- URL: buildwithjesus.com/es; lang="es"; og:locale es_ES; canonical /es.
- Guide links -> www.onetoeight.guide/es/... ; nav links stay inside each locale;
  switcher and hreflang on every page.

## Prices and dates

- "Founding price" = precio fundador; "coming soon" = Próximamente.
- Amounts keep the English shape with (AUD): "$19.99 (AUD)", "$29.99 (AUD)", "$69.99 (AUD)",
  "$1,000 (AUD)" - all on the machinery keep list, so bare price runs stay identical.
- Dates: "1 de diciembre de 2026"; "until" = hasta el; "then" = luego.
  Shape: "Precio fundador $19.99 (AUD) hasta el 1 de diciembre de 2026, luego $29.99 (AUD)."
- Leaders guide: coming soon at $69.99 (AUD), "Dentro de la guía" section heading.
