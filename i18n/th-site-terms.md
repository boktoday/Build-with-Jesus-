# Site term sheet - Thai (th-TH)

Scope: buildwithjesus.com (site copy, not the guide).
Base: the guide's Thai term sheet (same voice) extended with site terms.

## Voice

- Address the reader as "คุณ". Warm, plain, short sentences; no ครับ/ค่ะ politeness particles
  in the site voice; no stiff officialese (ภาษาราชการ); no "มัน" as a filler.
- Machine-Thai watchlist: never translate idioms literally; everyday Thai a young person
  reads without wincing.
- No em dashes or en dashes; no "วัยรุ่น" ever. Western digits; entities stay entities.

## Term locks (site)

- young people -> คนรุ่นใหม่ (NEVER "วัยรุ่น"); adults -> ผู้ใหญ่
- church -> คริสตจักร; community -> ชุมชน; charities -> องค์กรการกุศล;
  religious schools -> โรงเรียนศาสนา; homeschool families -> ครอบครัวโฮมสคูล
- agent -> เอเจนต์; the agent (nav) -> Agent
- leaders guide -> คู่มือผู้นำ; workshop -> เวิร์กช็อป; programme -> โปรแกรม
- the guide -> คู่มือ; The Guide (footer) -> คู่มือ
- build (verb) -> ลงมือทำ; build (the activity) -> การลงมือสร้าง; build day -> วันลงมือทำ
- the Eight Essentials -> แปดสิ่งจำเป็น; movements: Learn. Build. Give. -> เรียนรู้ ลงมือทำ แบ่งปัน
- Follow Jesus -> ติดตามพระเยซู; Give them away -> แบ่งปันออกไป
- school term -> ภาคเรียน; laptop -> แล็ปท็อป; phone -> โทรศัพท์; screen -> หน้าจอ;
  feed -> ฟีด; message -> ข้อความ; notification -> การแจ้งเตือน; screen time -> เวลาหน้าจอ

## Scripture policy on translated pages

Thai has no verified edition yet, so scripture quotes stay English with WEB named, as on
the ms pages; citation lines carry the Thai book name and the WEB label.

## Meta

- URL: buildwithjesus.com/th; lang="th-TH"; og:locale th_TH; canonical /th.
- Guide links -> www.onetoeight.guide/th/... ; nav links stay inside each locale;
  switcher and hreflang on every page.

## Prices and dates

- "Founding price" = ราคาเปิดตัว; "coming soon" = เร็ว ๆ นี้.
- Amounts keep the English shape with (AUD): "$19.99 (AUD)", "$29.99 (AUD)", "$69.99 (AUD)",
  "$1,000 (AUD)" - all on the machinery keep list, so bare price runs stay identical.
- Dates: "1 ธันวาคม 2026"; "until" = ถึง; "then" = จากนั้น.
  Shape: "ราคาเปิดตัว $19.99 (AUD) ถึง 1 ธันวาคม 2026 จากนั้นเป็น $29.99 (AUD)"
- Leaders guide: coming soon at $69.99 (AUD), "ในคู่มือ" section heading.
