# Site term sheet - Korean (ko-KR)

Scope: buildwithjesus.com (site copy, not the guide).
Base: the guide's Korean term sheet (same voice, LOCKED items) extended with site terms.

## Voice

- Register: **해요체** (polite, warm, conversational: "…해요 / …예요 / …거예요"). Never 합쇼체
  ("…합니다") in body prose, never 반말.
- Address the reader WITHOUT pronouns; Korean naturally drops them. "당신", "너희", and the
  teen words 십대 / 청소년 / 10대 / 틴에이저 are BANNED (hard check at assembly).
- No em dashes or en dashes; use ":" or commas or parentheses. Hyphen inside "Wi-Fi" and
  brand names stays. Ranges use 에서…까지 ("13세에서 23세까지").
- Western digits; entities stay entities.

## Term locks (site)

- young people -> 젊은 세대; adults -> 어른(들)
- church -> 교회; community -> 공동체; charities -> 자선 단체;
  religious schools -> 종교 학교; homeschool families -> 홈스쿨 가정
- agent -> Agent (keep English, per the guide editions); the agent (nav) -> Agent
- leaders guide -> 리더 가이드; workshop -> 워크숍; programme -> 프로그램
- the guide -> 가이드; The Guide (footer) -> 가이드
- build (verb) -> 만들다; build (the activity) -> 만들기; build day -> 빌드 데이
- the Eight Essentials -> 여덟 가지 핵심; movements: Learn. Build. Give. -> 배우기. 만들기. 나누기.
- Follow Jesus -> 예수님을 따라가요; Give them away -> 나눠 줘요
- school term -> 학기; laptop -> 노트북; phone -> 휴대폰; screen -> 화면;
  feed -> 피드; message -> 메시지; notification -> 알림; screen time -> 화면 보는 시간

## Scripture policy on translated pages

The kor edition ships and is verified, so quotes come from it exactly, from the local file,
with the translation named (1910 한글 성경) and Korean book names. No English fallback needed.

## Meta

- URL: buildwithjesus.com/ko; lang="ko-KR"; og:locale ko_KR; canonical /ko.
- Guide links -> www.onetoeight.guide/ko/... ; nav links stay inside each locale;
  switcher and hreflang on every page.

## Prices and dates

- "Founding price" = 출시 기념 가격; "coming soon" = 곧 출시.
- Amounts keep the English shape with (AUD): "$19.99 (AUD)", "$29.99 (AUD)", "$69.99 (AUD)",
  "$1,000 (AUD)" - all on the machinery keep list, so bare price runs stay identical.
- Dates: "2026년 12월 1일"; "until" = 까지; "then" = 이후.
  Shape: "출시 기념 가격 $19.99 (AUD), 2026년 12월 1일까지, 이후 $29.99 (AUD)."
- Leaders guide: coming soon at $69.99 (AUD), "가이드 안에는" section heading.
