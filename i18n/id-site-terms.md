# Site term sheet - Bahasa Indonesia (id-ID)

Scope: buildwithjesus.com (site copy, not the guide).
Base: the guide's Indonesian term sheet (same voice) extended with site terms.

## Voice

- Address the reader as "kamu"; warm, modern, plain Indonesian. NOT word-for-word translation.
- Machine-Indonesian watchlist: no stiff bureaucratic phrasing, no overuse of "silakan",
  no word-for-word English order. Everyday Indonesian a young person reads naturally.
- Indonesian forms, NOT Malay: bisa (not boleh), karena (not kerana), layar (not skrin),
  ponsel/HP (not telefon), menit (not minit), pesan (not mesej), unggah (not muat naik),
  konten (not kandungan), komunitas (not komuniti).
- No em dashes or en dashes; no "remaja" ever. Western digits; entities stay entities.

## Term locks (site)

- young people -> anak muda (NEVER "remaja"); adults -> orang dewasa
- church -> gereja; community -> komunitas; charities -> lembaga amal;
  religious schools -> sekolah keagamaan; homeschool families -> keluarga homeschool
- agent -> agent (loanword, matching the ms edition and the guide editions); the agent (nav) -> Agent
- leaders guide -> panduan pemimpin; workshop -> lokakarya; programme -> program
- the guide -> panduan; The Guide (footer) -> Panduan
- build (verb) -> membangun; build (the activity) -> berkarya; build day -> hari berkarya
- the Eight Essentials -> Delapan hal esensial; movements: Learn. Build. Give. -> Belajar. Berkarya. Berbagi.
- Follow Jesus -> Ikuti Yesus; Give them away -> Bagikan semuanya
- school term -> semester; laptop -> laptop; phone -> HP; screen -> layar; feed -> linimasa;
  message -> pesan; notification -> notifikasi; screen time -> waktu layar

## Scripture policy on translated pages

The ind edition ships (48 books - full NT plus most OT; Psalms NOT included) and is
verified, so quotes come from it exactly, from the local file, with the translation
named and Indonesian book names. Passages in books the edition lacks (e.g. Psalms 90:17)
stay English with WEB named, as on the ms pages.

## Meta

- URL: buildwithjesus.com/id; lang="id-ID"; og:locale id_ID; canonical /id.
- Guide links -> www.onetoeight.guide/id/... ; nav links stay inside each locale;
  switcher and hreflang on every page.

## Prices and dates

- "Founding price" = Harga pendiri; "coming soon" = Segera hadir.
- Amounts keep the English shape with (AUD): "$19.99 (AUD)", "$29.99 (AUD)", "$69.99 (AUD)",
  "$1,000 (AUD)" - all on the machinery keep list, so bare price runs stay identical.
- Dates: "1 Desember 2026"; "until" = hingga; "then" = lalu.
  Shape: "Harga pendiri $19.99 (AUD) hingga 1 Desember 2026, lalu $29.99 (AUD)."
- Leaders guide: coming soon at $69.99 (AUD), "Di dalam panduan" section heading.
