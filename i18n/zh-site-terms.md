# Site term sheet - Chinese, Simplified (zh-CN)

Scope: buildwithjesus.com (site copy, not the guide).
Base: the guide's Chinese term sheet (same voice, LOCKED items) extended with site terms.

## Voice

- Register: **你** (informal, standard). Simplified characters (简体中文) throughout.
- No em dashes or en dashes; use ，。、 or ： instead. Full-width punctuation for Chinese prose.
- No "青少年" ever. Western digits inside Chinese text are fine; entities stay entities.

## Term locks (site)

- young people -> 年轻人 (NEVER "青少年"); adults -> 成年人
- church -> 教会; community -> 社群; charities -> 慈善机构;
  religious schools -> 宗教学校; homeschool families -> 在家教育的家庭
- agent -> Agent (keep English, per the guide editions); the agent (nav) -> Agent
- leaders guide -> 带领者指南; workshop -> 工作坊; programme -> 项目
- the guide -> 指南; The Guide (footer) -> 指南
- build (verb) -> 建造; build (the activity) -> 动手建造; build day -> 建造日
- the Eight Essentials -> 八大要素; movements: Learn. Build. Give. -> 学习。建造。给予。
- Follow Jesus -> 跟随耶稣; Give them away -> 把它们送出去
- school term -> 学期; laptop -> 笔记本电脑; phone -> 手机; screen -> 屏幕;
  feed -> 信息流; message -> 消息; notification -> 通知; screen time -> 屏幕时间

## Scripture policy on translated pages

The cmn-cu89s edition ships and is verified, so quotes come from it exactly, from the local
file, with the translation named (和合本) and Chinese book names. Keep the edition's own
full-width punctuation and spacing exactly as fetched.

## Meta

- URL: buildwithjesus.com/zh; lang="zh-CN"; og:locale zh_CN; canonical /zh.
- Guide links -> www.onetoeight.guide/zh/... ; nav links stay inside each locale;
  switcher and hreflang on every page.

## Prices and dates

- "Founding price" = 首发价; "coming soon" = 即将推出.
- Amounts keep the English shape with (AUD): "$19.99 (AUD)", "$29.99 (AUD)", "$69.99 (AUD)",
  "$1,000 (AUD)" - all on the machinery keep list, so bare price runs stay identical.
- Dates: "2026年12月1日"; "until" = 截止; "then" = 之后.
  Shape: "首发价 $19.99 (AUD)，截止2026年12月1日，之后为 $29.99 (AUD)。"
- Leaders guide: coming soon at $69.99 (AUD), "指南内容" section heading.
