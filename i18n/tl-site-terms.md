# Site term sheet - Tagalog / Filipino (tl-PH)

Scope: buildwithjesus.com (site copy, not the guide). Pilot: homepage live 8 Oct 2026.
Base: the guide's Tagalog term sheet (same voice) extended with site terms.

## Voice

- Address the reader as ka / ikaw / mo; no "po", no "kayo"/"ninyo" in prose.
- Conversational but written; English loans Filipinos actually use are correct
  (cellphone terms, screen, feed, app, notifications, set-up, workshop, build).
- No em dashes or en dashes; no "tinedyer"/"teenager" ever.
- Western digits; entities stay entities; brand names stay English.

## Term locks (site)

- young people -> kabataan (never "tinedyer"/"teenager"); adults -> matatanda
- youth group -> grupo ng kabataan; church -> simbahan; community -> komunidad;
  charities -> kawanggawa; religious schools -> relihiyosong paaralan;
  homeschool families -> homeschool na pamilya
- agent -> agent (loanword, per the guide editions); the agent (nav) -> Agent
- leaders guide -> gabay ng mga lider; workshop -> workshop (loan); programme -> programa
- the guide -> ang gabay; The Guide (footer) -> Ang gabay
- build (verb) -> gumawa; build (the activity, loan) -> build; build day -> araw ng paggawa
- the Eight Essentials -> Ang Walong Mahalaga; the eight essentials (prose) -> ang walong mahalaga
- the eight locked names: Ang kakayahang maupo sa katahimikan / Ang katawan mo ay tahanan /
  Mga kasanayang magagamit sa totoong buhay / Digital na pagtatanggol sa sarili /
  Tunay na komunidad / Kaalaman kahit walang Wi-Fi / Ireseta ang kalikasan /
  Mga paniniwalang nananatili
- Follow Jesus -> Sumunod kay Jesus; Give them away -> Ipamigay ang mga ito
- Learn. Build. Give. -> Matuto. Gumawa. Ibigay.
- school term -> markahan; laptop -> laptop; admin access -> admin access;
  notification -> notification; message -> mensahe; screen -> screen
