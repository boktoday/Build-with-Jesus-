你可以做什么

你所做的一切，身旁都有一位助手。

Build with Jesus 的 Agent 不是那种你只去访问一次的聊天机器人。它是工作身旁的助手：陪你读经文，按你的节奏带你走过八大要素，为真实项目当教练，帮你做出值得留下的东西；你的问题再多，它也从不厌烦。下面就是它实际的样子。

认识 Agent 面向年轻人的免费指南

为年轻人，也为走在同一条路上的成年人。

认认真真学经文。

不是披着圣经外衣的搜索框，而是坐在你身旁的读者。

什么都可以问

这节经文是什么意思？以赛亚当时是在对谁说话？这段经文为什么重要？直接问就好，回答会把经文放在眼前，并注明每一处引用的出处。

逐字引用

每一处圣经引用都照抄自真实发布的译本，并始终写明是哪一个。绝不凭模型的记忆。你若要查，它就在那里。

深入探索

打开一个要素或一段经文，往深处走：走路去学校时听的语音摘要、一节课、一首诗，或一首关于这段经文的歌，适合读，也适合听。

藏在心里

用来背诵的经文、每天一首诗、记得住的歌。诗篇作者没有把它收藏在手机里。Agent 帮你把它变成真正属于自己的东西。

单人模式

如果你要的只是圣经，说一声就好。单人模式只陪你读经文，别的什么都不做。没有杂音，没有多余的东西。

难回答的问题

疑惑、悲伤、那些说不通的部分。Agent 不会把它们糊弄过去。它指向经文本身；至于沉重的事，它指向你身旁真实的人。

把想法变成项目。

一次一件真实的东西，做完，送出去。

只挑一件

Agent 帮你选定一个真实项目：它是什么、为谁而做、做成什么样子才算完成。然后它和你一起写计划，一步一步来。

当教练，不代劳

它把工作拆成一个个晚上，而不是一篇篇大文章。它问出下一个问题，记下进度，卡住的地方就轻轻推一把。动手建造的始终是你。这才是重点。

建造的线索

每天早上，它都能说出下一个小动作：今天给大厅做公告栏的边框，明天用砂纸打磨栖木。小步前进，步步踏实，直到真正做完。

把它交出去

完成的东西会交到真实的人手里：你的教会、你的青年团契、你的家人。Agent 帮你把它送到，标记为完成，等你准备好时再开始下一件。

做出真实的东西。

Agent 是工作坊，不是玩具柜。

学习材料或一节课

上周日讲道的讨论问题、给团体用的一页学习材料、一节在浏览器里运行的互动课程。

一首歌、一首诗、一段视频

真正的歌曲和朗诵作品，和你一起写，认真收尾。一点点花费都会先说清楚，花出去之前都会先经你确认。

为一件真实的事做个页面

你教会的欢迎页面、颂歌之夜的邀请函、你们团队真正在用的轮值表。小巧、利落，不用注册，不用装 App。

带得走的技能

在做出一件东西的同时，你也在学会怎么做：计划、写作、设计，以及与 AI 协作而不被它支配。

把八大要素走一遍。

one to eight 指南，路上有伙伴同行。

免费指南带你走过八大要素，从预备到信仰，按你自己的节奏，用你自己的语言。Agent 陪你一起走：打开每一个要素，讲解你不确定的地方，安排每天的小步骤；你停下一周再回来时，它帮你把线索接上。

保持节奏，也保持警醒。

每天一点小习惯，方向摆正。

与 Agent 的一天

清晨一段祷告或一分钟开场，下午一次问候，晚上一段经文。温和的结构，你可以调低，也可以关掉。

规划时段

当生活像堆成一座山：一个时段、几个问题，一份贴合真实一周的计划。然后回到建造。

是助手，不是伙伴

它不会假装是你的朋友。它温暖、诚实；遇到必须由真人来做的事，它会把你带到真实的人那里。

默认私密
