它是什么

一本为负责开展的成年人写的指南。写给带领的人，而不是动手建造的人，好让你把注意力给年轻人，而不是埋在行政事务里。

一个学期，一条路径。

整个项目按周铺开：读什么、建造什么，以及卡住时该说什么。跟着这条路走，或者按你自己的节奏来。

每一次建造，都已备好。

六个建造项目，每一个都配齐你需要的东西：年轻人会做出什么、建造日如何运作，以及该对父母和监护人说什么。

圣经，用心对待。

如何在 Agent 的帮助下带领阅读：它在哪里教导、在哪里停下，以及如何把一个好问题带回给你的教会和带领者。

一个年轻人，还是二十个。

在家教育的书桌只坐一个人、宗教学校的一个班、二十人的青年团契、星期六的慈善机构小队：都装得下。指南适应的是房间的大小，而不是工作量。

同一件事的两半

Agent 和年轻人一起工作。指南和你一起工作。

年轻人得到 Agent。 它陪他们一起阅读，教他们技能，陪他们完成建造，帮他们收尾和交付。本地优先，运行在他们自己的设备上。一旦设置好并正常运转，大部分互动都可以在手机上通过 Telegram 或 WhatsApp 完成：提问，对作品快速迭代，无论这一天把他们带到哪里。

你得到计划。 一周又一周：开展什么、留意什么，以及学期变忙时如何让它继续推进。

你始终是老师。 Agent 从不取代你的教会和带领者，指南会一直守住这一点。每一个好问题都会回到你这里。

一用再用。 这个学期开展一轮，下个学期换一个新团体再来一轮。一次购买，覆盖你带领的每个团体。

指南内容

一次购买，全部涵盖：指南、手册和可打印工具包。即将推出。

一周又一周。

整个项目沿着八周铺开：读什么、建造什么，以及卡住时该说什么。

六本建造手册。

欢迎卡、轮值表、送餐接力、学习单、活动页面、慈善商店橱窗：年轻人会做出什么，以及这一天如何进行。

快速开始。

你的前三次活动，让你在学期还没开始前，就能看到它在房间里运转起来。

可打印工具包。

致父母和监护人的信、许可与隐私说明、建造日清单、交接卡，以及贴在冰箱上的一页速查表。

带领阅读。

如何在 Agent 的陪伴下带领一次阅读，以及 Agent 究竟在哪里停下。每一个好问题都会回到你的教会和带领者那里。
