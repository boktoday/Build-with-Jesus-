什么是 Build with Jesus？

耶稣学习各样手艺，一有机会就教导人，敢于冒险，动手建造，也常常把东西送出去。

Build with Jesus 是要用最新的工具，主要为年轻人、他们的教会和更广大的社群建造数字作品。

今天，我们有 AI 技术，让任何年轻人都能建造自己的软件，并用 AI Agent 提升学习与效率。此外，建造还有许多其他形态；one to eight 指南和他们的 AI Agent 也鼓励年轻人参与数字世界之外的活动。

学习。建造。给予。

整个理念，浓缩在每天三个动作里。指南教导八大要素；圣经和 Agent 与他们同行；这一周的成果最终交到别人手中。

1

学习

一节短课，按你的节奏来：八大要素，一次学一项技能。计划、专注、与 AI 协作、把开始的事情做完。每项技能都会落到同一周的建造里，所以是在做中学到的。

2

建造

每天在一个真实项目上迈出一小步：个人的软件、为家人做的东西，每个学期还有为教会做的东西。八大要素把技艺与品格一同传授。

3

给予

完成的东西会被送出去：在青年团契上展示，交到教会办公室，或挂在公告栏上派上用场。没有东西会躺在文件夹里。给予才是重点。

这背后是谁

Build with Jesus 由 Brendan O’Keefe 制作。他创立了 onetoeight 并撰写了 one to eight 指南，这本免费实用指南面向年轻人，现在有十种语言的读者；他还四处奔走，在各地教会现场举办 Build with Jesus 工作坊。

Agent、课程和这个网站，都用年轻人建造的方式建造：从小处开始，在动手做中学习，好好收尾，再把完成的东西送出去。

教会最先问的问题

这是替他们做圣经学习的 AI 吗？

不是。它帮助讲解经文、维持节奏，每个值得问的问题都会回到你的教会和带领者那里。教导始终由人来做。

它是给谁的？

想动手建造的基督徒年轻人，无论还在上学还是刚离开学校；也包括想要走同样道路的成年人，独自一人或与朋友一起都行。节奏由他们自己掌握，一切都发生在他们自己的设备上。

教会要开始，需要什么？

一个真实的需要，一间有 wifi 的房间。建造日就是星期六。其余的就是指南和 Agent，第一次我们会全程带你走一遍。

费用是多少？

Agent 首发价 $19.99 (AUD)，截止2026年12月1日，之后为 $29.99 (AUD)，一次付款，永久归你所有。指南免费阅读，带领者指南即将推出，价格为 $69.99 (AUD)，一次购买即可覆盖每位带领者、每个团体，以及你举办的任意多场工作坊；建造日则与各教会具体商定。我们也会为有需要的家庭准备赞助名额。

年轻人需要什么？

一台有管理员权限的个人笔记本电脑或台式机（不是学校的笔记本电脑），一个带 $20 额度的 OpenRouter 账户，以及手机上免费的 Telegram 或 WhatsApp 账号。设置大约需要一小时，入门引导会手把手带他们完成。

他们能从手机上使用吗？

可以，很多时候都可以。Agent 设置好并正常运转后，年轻人的大部分互动都可以在手机上通过 Telegram 或 WhatsApp 完成：提问、记录想法，并随时随地快速迭代自己的作品。笔记本电脑是工作台，手机让思路继续流动。
