什么是 AI Agent

AI Agent 是一种由人工智能驱动的软件系统，能够自主规划、做出决策、使用外部工具，并执行多步骤的工作流来实现特定目标。

与只会对单条提示生成文本回复的普通聊天机器人不同，AI Agent 在一个持续循环中运行：推理、行动、观察结果，并调整下一步，直到任务完成。

它实际上是什么

说白了：一份完整的 Agent 配置，运行在本人自己的设备上，专为这项工作打造。为年轻人而建，也为想走同一条路的成年人而建。

一份完整的 Agent 配置。

不是一个内嵌机器人的聊天窗口。年轻人得到的是一份完整的配置：一个性格、对一路走来的记忆、它能运行的技能，以及内置的每日节奏。

基于 Hermes Agent 构建。

Hermes Agent 是 Nous Research 出品的开源个人 Agent。它运行在年轻人自己的电脑上，支持 Windows、macOS 或 Linux。

本地优先，保持私密。

配置就装在年轻人自己的设备上，作品本身也在那里保持私密。他们的笔记、他们的祷告和他们的作品，始终属于他们自己。

一种节奏，不是信息流。

带音频的清晨一分钟、午后的一次问候，还有一份为明天准备的计划。Agent 一路串起学习、建造和给予，并提醒他们正在做什么、为谁而做。

它会和他们聊天。

清晨一分钟以音频送达，手机上还一直开着一条对话，所以是这一天主动找到他们，而不是等着被打开。

背后是你自己的模型。

它连接你选择的 AI 模型，安装引导会手把手带你完成，直到它顺利运行。不需要任何技术背景。

Build with Jesus 版本增加了以圣经为核心的设置：它帮助讲解经文、带领祷告，并且始终把方向指回本地教会。

它做什么：从清晨到交接

每天一件小事，按他们自己的节奏。Agent 在三个动作之间串起一条线。

1

学习

按年轻人的节奏带领八大要素：静默、身体、技能、数字自卫、社群、知识、自然、经过考验的信念。一次一项，边做边学。

2

建造

在年轻人自己的电脑上，一步步陪伴建造。项目停滞时帮它重新动起来，并在完成时一起庆祝。

3

给予

帮助好好收尾，然后把作品交给它为之而做的教会或社群。没有东西会躺在文件夹里。

Agent 基于 one to eight 指南构建，随第一批建造小组一同推出。

设置它，你需要准备什么

这是一次按你自己节奏进行的建造，不是魔法安装。想充分发挥 Agent 的作用，你需要先把这些东西准备好。它们都不贵，但都是实打实的。

1

你自己的笔记本电脑

一台运行 Windows、macOS 或 Linux 的个人笔记本电脑或台式机，年轻人对它拥有完整的管理员权限。不要用学校的笔记本电脑：学校发放的机器通常会阻止软件安装、注销后会重置，这会让 Agent 无法工作。

最低配置： 8 GB 内存、2 GB 可用存储空间，以及 2018年之后出厂的任何设备。

2

一个带 $20 额度的 OpenRouter 账户

在 openrouter.ai 账户上一次性充值 $20 的额度。该额度覆盖初始的 Agent 构建和个性化设置，并让你通过同一个按量付费的网关使用领先的模型（DeepSeek、Kimi、Qwen、GLM 等）。

设置完成后，日常使用运行在低成本的云端模型上；轻度日常使用每月大约 $5 到 $10，从同一笔额度里扣。为更深入的功能（个性化、课程深入讲解、歌曲和视频）留一点余额，最初的 $20 通常够用一两个月。

3

可选：一个小型本地模型

对于较轻的离线任务，Agent 可以运行在设备本地安装的小型模型上，这些对话就保持离线，也没有按条计费的成本。这是一个进阶的附加项，完全可选：这份配置出厂即适配上面提到的云端模型，之后想要也可以再加装本地模型。

4

Telegram 或 WhatsApp

清晨一分钟的音频和每日问候都以消息的形式送达，所以他们的手机上需要一个免费的 Telegram 或 WhatsApp 账号。消息一对一发来，不走群聊：没有垃圾信息，我们也不会收集关于他们的任何资料。只是一句早安和一份当天的计划。而且，一旦 Agent 设置好并正常运转，很多互动都可以直接在手机上完成：提问、记录想法，无论一天把他们带到哪里，都能快速迭代自己的作品。

它不会做的事

护栏，用大白话说。

它不会取代你的教会。 每一个真实的问题都会被送回他们的牧师、他们的带领者和他们的教会大家庭。

它不会编造经文。 经文对照指明的译本逐句核实，每一行信仰内容在发布前都由真人审阅。

它不会用辩论把任何人带进信仰，也不会把任何人辩离信仰。 它教导，它提问，也为圣灵留出空间。

它不会试图和你做朋友。 它是助手，它的职责是把他们送回真实世界，手里拿着完成的作品。

大家最先问的问题，不加粉饰地回答。

那它到底是什么？一个 App、一个下载包，还是一个聊天机器人？

一款一次安装、有人陪伴的软件：一份完整的 Agent 配置，装在年轻人自己的电脑上，你们跟着书面引导，用一个晚上就能一起设置好。之后他们实际看到和做的：一条对话线每天早晨用音频送上当天的阅读，他们可以就经文提问，有每周一项的技能，他们的建造也在电脑上被一步步陪着推进。它永远不会取代你的教会，而是把你指回那里。

我们需要哪些设备和账号？

一台有管理员权限的个人笔记本电脑（Windows、macOS 或 Linux）、一个带 $20 额度的 OpenRouter 账户，以及手机上一个免费的 Telegram 或 WhatsApp 账号。全部就是这些，细节都在上面的设置部分。

需要另外的 AI 订阅吗？

不需要。$20 的 OpenRouter 额度是按量付费，不是订阅：轻度日常使用低成本模型，每月大约 $5 到 $10，从这笔额度里扣，快用完时再充值就好。不会有任何你没主动选择的账单。

完整的 Agent 配置（清晨一分钟、八大要素、建造引导、以圣经为核心的设置）、书面安装引导，以及随项目发展提供的配置更新。

手机还是笔记本电脑？

两者都要，各有各的用途。笔记本电脑是 Agent 所在的地方，也是动手建造的地方。但一旦它设置好并正常运转，年轻人的大部分互动都可以来自手机，通过 Telegram 或 WhatsApp：提问、记录想法，无论身在何处，都能快速迭代自己的作品。需要移动时就有移动，真正的工作则在他们重新坐回电脑前时等着他们。
