安全与数据

大白话版本。

写给父母、带领者和教会理事会：什么内容保持私密，这个网站收集什么，以及由谁负责。

什么留在原地

年轻人做的每一件作品都留在他们自己的设备上，不会上传给我们；未经成年带领者先审阅，什么都不会发布出去。

教会的数据留在教会。 项目在年轻人自己的电脑上运行，服务的是本地团体，任何东西都不会被汇集到共享平台。

数据会流向哪里

本地优先，而且我们如实相告。课程、作品、文件和圣经译本都留在年轻人自己的设备上，不会上传给我们。

他们给 Agent 发消息时，消息会送到他们在自己 OpenRouter 账户里选择的 AI 模型；日常消息则像普通聊天消息一样经由 Telegram 或 WhatsApp 传输。OpenRouter 和各家模型供应商执行各自的数据政策。OpenRouter 上是否保留提示词，始终由用户主动选择。OpenRouter 从未向任何第三方分享、出售或授权底层提示词数据。他们说明了哪些供应商可能会采集数据用于训练，并提供设置，让你控制自己的提示词可以如何被使用。详情见 OpenRouter 的零数据保留文档.

会到我们这里的东西：没有什么会自动送达。 我们能看到的，只有你通过电子邮件或表单主动发来的内容，别的都看不到。

他们身旁的 Agent

是助手，不是伙伴。

这是一个个人助理，也是一个 AI Agent。它主要是思考上的伙伴和教练，帮助年轻人更有条理、更高效、学到新技能。归根结底，它鼓励基于项目的学习和动手建造。它把时间还给他们，让这些时间回到真实世界里，用在生活技能和真实本领上：靠动手去做来学会，而不是靠谈论。我们做的工具会把你送回真实世界，而不是试图成为你朋友的那种。

Agent 是助手，绝不是权威。教导的事，它总是把你指回你的教会和你的带领者；它这样设计，就是要让带领者始终是老师。

经文照我们随附的译本逐字引用，每一处引用都注明是哪个译本。Agent 绝不编造经文；每一行信仰内容在发布前都由真人审阅。

这个网站收集什么

有两个表单：订阅框和工作坊报名表。你在里面填写的内容（姓名、电子邮箱，以及教会或机构名称），我们只保留用来回复你，除此之外什么都不留。

访问量由一个很小的访问计数器统计，它不使用 cookies，也不会建立关于你的画像。这个网站没有账户、没有追踪像素，也没有广告。

年轻人和带领者

项目的开展全程都有带领者在场，并遵守主办教会的安全保护政策。年轻人绝不会和成年辅导员单独相处，所有工作都在明处进行；每一件作品在靠近公共互联网之前，都会先由带领者过目。

写给父母和监护人

如果年轻人未满18岁，整套设置由成年人负责：支付 AI 使用费的 OpenRouter 账户由父母或监护人创建并付款，消息账号也在他们知情的情况下设置。我们建议第一次安装一起完成。

设置清单： 一起创建 OpenRouter 账户并充入 $20 额度；把 Agent 安装在他们自己的笔记本电脑上（不是学校的电脑）；约定每天的节奏：早上一则消息，白天一次问候；头两周把笔记本电脑放在家里的共用空间。

Agent 只一对一地发消息，绝不进入群聊；父母随时可以要求查看每一条消息。设置最好由一位成年人和年轻人一起完成，第一次大概需要花一个晚上。
